# Celestial Sword Mod

A Fabric mod for Wang Lin's Celestial Sword with three abilities.

## Features

- Adds Wang Lin's Celestial Sword to the game
- Three unique abilities: God Slaying, Underworld River Technique, and more

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/celestial-sword-mod/releases)
2. Place the mod in your `mods` folder
3. Launch Minecraft with Fabric Loader

## Usage

1. Craft or obtain the Celestial Sword
2. Use the abilities with the right-click and left-click actions

## Configuration

The mod does not have any configuration options at this time.
